# Iris Hale

Independent researcher working on AI memory systems, long-term memory for LLM agents, and structured memory architectures.

## Research Interests

- Long-term memory for LLM agents
- Structured memory systems
- Coordinate-based memory
- Retrieval-augmented generation
- AI agent architecture
- White-box memory and auditability

## Current Work

I am developing and evaluating a Coordinate-Based Memory System (CMS), a structured memory abstraction for persistent conversational agents.
